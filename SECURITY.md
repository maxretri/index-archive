# Security policy

Please do not publish exploitable security reports in a public issue. Send maintainers a private report with the affected version, reproduction steps, impact, and any suggested mitigation. Configure a project security contact before the first public release.

Never include real bot tokens, Telegram initData, Supabase keys, session tokens, user IDs, or Telegram file IDs in reports or test fixtures.

INDEX handles private archives but does not implement client-side encryption or claim end-to-end encryption. Files sent to the bot are handled by Telegram and the deployed INDEX server.
